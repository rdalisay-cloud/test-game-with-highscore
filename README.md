# Compass Enrolments (UI replica)

UI-only replica of the Compass Enrolments microfrontend for sharing design and flow changes via Cursor Apps.

Uses sample data only. Not connected to Compass APIs, GraphQL, or a school.

## Screens

- Staff-first enrolments dashboard
- Parent enrolments dashboard
- Parent self-registration portal

## Local

```bash
npm install
npm run dev
```
